Neon Coast Cover Studio: a free, offline web app that turns your own photos into GTA-style multi-panel poster cover art. Pick a layout (nine-panel cover grid, hero + trio, four corners, full bleed, tilted snapshots), grade it with a Vice City sunset or neon night map, letter your caption in bold condensed type with a neon script subtitle, then export a PNG in 1080×1080, 1080×1350, 1920×1080 or 1080×1920 — one click, no upload, your photos never leave the browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
